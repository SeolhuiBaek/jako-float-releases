# JAKO FLOAT

**일상 위에 떠 있는 일본어 단어장**

JAKO FLOAT는 다른 작업을 하면서도 일본어 단어를 가볍게 반복 학습할 수 있도록 설계된 Windows 데스크톱 학습 앱입니다.

## 다운로드

현재 공개 배포를 준비하고 있습니다. 설치 파일은 아직 게시되지 않았습니다.

공개 버전이 게시되면 [Releases](https://github.com/SeolhuiBaek/jako-float-releases/releases)에서 설치 파일, 버전별 변경 사항 및 SHA256 확인 정보를 제공할 예정입니다.

## 주요 기능

- 작은 플로팅 카드로 일본어 단어 학습
- JLPT 급수별 단어장 및 검색
- 간격 반복 학습과 학습 진행률 관리
- 즐겨찾기 및 개인 학습 노트

## 설치 및 업데이트

공개 버전 설치 및 업데이트 안내는 정식 배포와 함께 제공됩니다. Windows 보안 경고를 무조건 무시하지 말고 배포 출처와 파일을 확인해 주세요.

이 저장소는 배포 파일과 이용 안내를 제공하기 위한 공간입니다. 앱 소스코드는 포함하지 않습니다.
